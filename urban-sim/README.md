# Urban Lab — 簡易都市シミュレーション

ブラウザだけで動く、教育・実験用の簡易エージェントベース都市モデルです。外部ライブラリやビルドは不要です。

## できること

- 住宅・商業・職場・公園・駅・道路・空き地をグリッド上に配置
- 住民ごとに所得、居住地、勤務地、満足度を保持
- 家賃・通勤距離・駅アクセス・公園・商業利便性・密度から居住効用を計算
- 不満のある住民が、より効用の高い空き住宅へ移転
- 住宅需要と入居率に応じて家賃が変動
- 都市全体の人口、平均家賃、平均通勤距離、満足度、空室率を可視化
- 土地利用／家賃／満足度／人口密度の4レイヤー表示

## 実行

`urban-sim/index.html` をブラウザで開くだけです。

ローカルHTTPサーバーを使う場合の例:

```bash
python3 -m http.server 8000
```

その後 `http://localhost:8000/urban-sim/` を開きます。

## モデル概要

各住民の住宅スコアは概ね次の要因から構成されます。

- 家賃負担: マイナス
- 通勤距離: マイナス
- 高密度: 一定以上でマイナス
- 近隣の公園: プラス
- 駅アクセス: プラス
- 近隣の商業: プラス

住民は毎年、現在の住宅とランダムに抽出した空き住宅を比較し、十分な改善が見込めるときに転居します。駅が自宅・勤務地の近くにある場合は実効通勤距離が短縮されます。

これは現実の都市を予測するモデルではなく、都市構造と住民選択の相互作用を直感的に観察するための簡略モデルです。
